# 奇门遁甲排盘系统

基于精准天文历算的奇门遁甲排盘工具，支持茅山奇门（转盘/飞盘）和时家奇门（拆补法/置闰法）四种排盘方式。

## 功能特性

- **四种排盘方式**：转盘排法、飞盘排法（茅山派）、拆补法、置闰法（时家传统派）
- **专业日期选择器**：公历/农历双模式切换，日历网格同时显示节气标记
- **天文精度历算**：
  - 内嵌 deltaT 天文数据表（1900-2100 年）
  - 基于 VSOP87 简化算法计算太阳视黄经（精度约 0.01°）
  - UTC → TDB（含 deltaT 修正）→ BJT（北京时间）完整时间链
- **九宫格可视化**：仿古纸张风格 CSS Grid 布局，展示天盘/地盘干支、九星、八门、八神
- **纯前端实现**：零依赖，浏览器直接打开即可使用

## 排盘方式说明

### 转盘 / 飞盘（茅山奇门）

| 项目 | 转盘排法 | 飞盘排法 |
|------|---------|---------|
| 九星 | 8 星（不含天禽），按洛书 8 宫顺时针旋转布宫 | 9 星（含天禽），按宫位序 1-9 飞布 |
| 八门 | 8 门按洛书 8 宫路径步进 | 8 门按宫位序飞布（不含 5 宫） |
| 八神 | 8 神：值符→螣蛇→太阴→六合→白虎→玄武→九地→九天 | 9 神：阳遁含勾陈/朱雀，阴遁含白虎/太常 |
| 5 宫寄宫 | 区分阴阳遁：**阳遁寄艮 8 宫(生门)，阴遁寄坤 2 宫(死门)** | 同左 |

### 拆补法 / 置闰法（时家传统）

| 项目 | 拆补法 | 置闰法 |
|------|--------|--------|
| 局数确定 | 根据当前节气 + 符头日（甲子/甲午/甲寅/甲申）查表得局 | 在拆补法基础上增加超神/接气判断 |
| 置闰规则 | — | 超神超过 9 天时回退一个节气并置闰 |
| 5 宫寄宫 | 固定寄坤 2 宫（死门），不区分阴阳遁 | 同左 |

### 两套引擎差异

- **转盘/飞盘引擎**（`calculateQimenPan`）：使用内嵌天文数据（deltaT 表 + 节气事件），TDB 时间系统，茅山派规则
- **拆补/置闰引擎**（`QimenDunjiaEngine`）：独立实现，使用 lunar.js 库进行农历计算，VSOP87 太阳视黄经算法，时家传统派规则

## 核心算法

### 时间系统

```
用户输入时间 → UTC (JD) → TDB = UTC + deltaT → BJT = UTC + 8h
```

- **JD（儒略日）**：统一时间基准
- **deltaT**：地球自转速率变化修正量，内嵌于源码中覆盖 1900-2100 年
- **TDB**：质心力学时，用于所有天文计算（节气时刻、阴遁阳遁判断）
- **BJT**：北京时间 (UTC+8)，用于日干支和时干支计算

### 干支系统

- **四柱推算**：年柱、月柱、日柱、时柱完整计算
- **旬首与空亡**：十日一旬（甲子/甲戌/甲申/甲午/甲辰/甲寅），每旬两位空亡
- **二十四节气**：精确到分钟级的节气交接时刻判定

### 九宫体系

```
┌─4 巽─┬─9 离─┬─2 坤─┐
│ 杜门 │ 景门 │ 死门 │
├─3 震─┼─5 中─┼─7 兑─┤
│ 伤门 │ 天禽 │ 惊门 │
├─8 艮─┬─1 坎─┴─6 乾─┤
│ 生门 │ 休门 │ 开门 │
└─────┴────────┴─────┘
```

- **洛书 8 宫顺时针路径**：1→8→3→4→9→2→7→6（坎→艮→震→巽→离→坤→兑→乾）
- **5 宫（中宫）**：天禽星寄居，无本位门，需特殊处理

### 排盘流程

#### 转盘 / 飞盘引擎（`calculateQimenPan`）

1. 计算四柱（年月日时干支）
2. 判断阴遁 / 阳遁（冬至→夏至为阳遁顺排，夏至→冬至为阴遁逆排）
3. 确定当前节气及上中下三元，查 `juShuYang` / `juShuYin` 表计算局数
4. 排地盘天干（以戊己庚辛壬癸丁丙乙顺序，按局数起始宫位排列）
5. 确定值符（旬首遁干落宫的本位星）和值使（对应本位门，5 宫按流派处理）
6. 排天盘九星（值符落宫起步，按时干飞转到时干落宫）
7. 排八门（值使落宫起步，按时支步进，5 宫线性步进后寄坤 2 宫）
8. 排八神（值符落宫起步，阳遁顺布、阴遁逆布）

#### 拆补 / 置闰引擎（`QimenDunjiaEngine`）

1. 使用 lunar.js 计算四柱和节气信息
2. 根据符头日地支确定上中下元（子午卯酉=上元，寅申巳亥=中元，辰戌丑未=下元）
3. 查 `JU_MAP` 表得局数（置闰法增加超神/接气判断与回退逻辑）
4. 排地盘天干、天盘干、九星、八门、八神（独立实现，不依赖转盘/飞盘引擎）

## 使用方法

1. 用浏览器打开 `index.html`
2. 点击日期输入框选择时间：
   - 默认**公历模式**，点击顶部标签可切换到**农历模式**
   - 日历网格同时显示公历日期、农历日期和节气标记
3. 选择排盘方式按钮开始排盘：
   - **转盘排法** — 茅山奇门转盘
   - **飞盘排法** — 茅山奇门飞盘
   - **拆补法** — 时家奇门拆补法
   - **置闰法** — 时家奇门置闰法
4. 查看排盘结果：
   - **信息卡片**：农历日期、四柱干支、当前节气、空亡、局数、值符/值使/直符
   - **九宫格图**：每个宫位显示八神、天盘干、九星、地盘干、八门

## 技术栈

| 技术 | 说明 |
|------|------|
| HTML/CSS/JavaScript | 纯原生实现，无第三方框架依赖 |
| CSS Grid | 九宫格布局（转盘/飞盘 flex 布局 vs 拆补/置闰 absolute 定位） |
| lunar.js | 农历转换库（提供 Solar/Lunar 类，支持公历/农历互转、八字获取、节气查询） |
| QimenDatePicker | 自定义日期选择器类（公历/农历双模式、水墨/经典两套主题、节气显示） |
| 内嵌数据 | deltaT 天文数据表 + 阳遁/阴遁局数映射表 (`juShuYang`/`juShuYin`) + 九宫信息 (`palacesInfo`) |
